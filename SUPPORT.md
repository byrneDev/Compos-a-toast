# Support

Compos-a-toast is pre-1.0 migration software maintained on a best-effort basis.

For usage questions, migration-format discussions, and feature proposals, use the
repository's GitHub Discussions area when available. Reproducible software defects can
use the bug-report issue form.

Before asking for help:

1. Reproduce the behavior with the latest `main` branch.
2. Run `npm.cmd test` and `npm.cmd run build`.
3. Reduce the problem to a newly authored synthetic fixture.
4. Include the application commit, Windows version, and relevant Captivate version.

Never publish or attach customer courses, proprietary media, credentials, personal
information, generated signing material, HTAs, or Flash executables. Security concerns
follow the private-first process in [SECURITY.md](SECURITY.md), not the support channel.
